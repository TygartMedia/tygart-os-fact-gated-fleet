**Dial tested:** wave 5's failure was a contract blind spot — both legs read a
dated-record page as current claims. Wave 6 adds the **page-class guard** to
both contracts: classify first (CURRENT-CLAIMS or DATED-RECORD); on a record,

written. The fixer agreed with the classification and the title check. The
wave-5 failure mode did not recur.

## The survivor — one bare restamp

On `physical-fulfillment-founding-subscriber-mailers`, classified
CURRENT-CLAIMS, the scout's single finding was a bare "Last verified"
restamp (Sep 23 → Nov 5), and the fixer confirmed it. Glint struck it: the
audit verified none of the page's substance (USPS rules, a book launch — all
NEEDS-VERIFY), so the stamp would assert a verification that never happened.
This is wave 5's meta-model class, and the two waves disagree: wave 5's
fixer refuted it, wave 6's confirmed it. **Fixer judgment on bare restamps
is inconsistent run-to-run** — which prices the next contract clause: a
"Last verified" restamp ships only when the audit actually verified the
page's substantive claims; otherwise it is REFUTE-class by rule, not by
judgment. That clause is wave 7's dial.
